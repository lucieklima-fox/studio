# **App Name**: Melody Maestro

## Core Features:

- Staff Note Identifier: Displays a random musical note on a staff (treble or bass clef) for the child to identify by clicking the correct note name or piano key. Provides instant feedback.
- Keyboard Note Finder: Presents a note name or plays a tone, challenging the child to find and click the corresponding key on the virtual piano keyboard. Provides instant feedback.
- Virtual Piano Keyboard: An interactive, responsive virtual piano keyboard spanning at least two octaves, providing authentic sound feedback when keys are pressed.
- Basic Progress Tracking: Keeps a score of correct answers and basic accuracy statistics to track the child's progress through different learning modes.
- Personalized Practice Generator: A generative AI tool that analyzes the child's performance to identify challenging notes or clefs and dynamically creates tailored practice exercises to improve weak areas.
- Engaging Audio-Visual Feedback: Utilizes playful animations, sound effects, and encouraging messages to provide immediate, positive, and gentle feedback for correct and incorrect answers.

## Style Guidelines:

- Primary color: A cheerful, warm orange-yellow (#E3A72C), evoking energy and playfulness, contrasting well with the light background.
- Background color: A very light, creamy hue (#F7F1E6), offering a clean and calm canvas for visual elements while maintaining warmth from the primary color's base hue.
- Accent color: A vibrant orange-red (#DB330B) used for call-to-action buttons, highlights, and positive feedback, creating a bold and dynamic contrast.
- Body and headline font: 'Poppins' (sans-serif) for a modern, geometric, and friendly look, suitable for large buttons, clear labels, and short instructional text for children.
- Utilize large, rounded, and clearly illustrative icons with musical themes (e.g., notes, clefs, piano keys) that are easily understandable by young children.
- Implement a spacious and uncluttered layout with generously sized, tactile interactive elements to ensure ease of use and navigation for children on both tablet and desktop devices.
- Incorporate smooth and delightful animations for positive feedback (e.g., a sparkling effect for correct answers), and gentle, non-punitive animations for incorrect responses.
